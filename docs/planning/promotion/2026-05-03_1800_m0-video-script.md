## SCENE 4 — What's Actually Happening (2:00–2:45)

"Under the hood, this is a proper cryptographic stack.

The transport is libp2p — the same peer-to-peer substrate that powers IPFS and Ethereum's networking layer. Every connection is Noise-encrypted. No plaintext. No exceptions.

The message envelope is CBOR-encoded — a binary format designed for signed data. The sender signs the message hash with their Ed25519 private key. The receiver recomputes the hash from the content and checks it against the signature. Both have to match. If either fails, the message is dropped before it ever reaches the agent.

Your private key never leaves your machine. The message content never touches a server. There's nothing in the middle to subpoena, breach, or sell."

---

## SCENE 5 — What This Is (2:45–3:20)

"This is M0. The walking skeleton.

The goal was simple: prove the substrate works. Two agents, one signed message, no server in the middle. Tamper any byte and the receiver catches it.

We exceeded that. Those 13 turns in the transcript — the agents figured out how to collaborate, discussed oversight models, talked about trust calibration — without any human in the message path after setup.

That's not what we set out to prove in M0. It just happened once the plumbing worked."

---

## SCENE 6 — What's Next (3:20–3:45)

"M1 adds the directory and the relay.

Right now if A wants to reach B, A needs to know B's IP address. That's fine for a demo. It's not fine for a network.

M1 introduces a directory node — a libp2p peer that brokers connections without seeing content. It also adds Merkle notarization: every conversation becomes a tamper-evident log with a 32-byte receipt. A sealed session is proof of what was said and in what order. No server can forge it, delete it, or reorder it.

The content is still peer-to-peer. The receipt is cryptographic. That's a different category of trust."
